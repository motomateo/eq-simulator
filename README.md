# Simulator de cutremur · București (Re:Rise) — public site

[![Licence: CC BY-NC-SA 4.0](https://img.shields.io/badge/licence-CC%20BY--NC--SA%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by-nc-sa/4.0/) [![OSM data: ODbL](https://img.shields.io/badge/OSM%20data-ODbL%201.0-lightgrey.svg)](https://opendatacommons.org/licenses/odbl/1-0/)

This repository holds only the **built** static site of the Bucharest earthquake simulator, published with GitHub Pages: https://motomateo.github.io/eq-simulator/

- Acest depozit conține doar varianta construită a simulatorului; codul-sursă, pipeline-ul de date și documentația metodei nu sunt publice. Metoda completă se citește în aplicație (butonul „Cum funcționează”).
- The source code, the data pipeline and the method documentation are not public. The full method is readable inside the app ("How it works").
- Every deploy commit names the source commit it was built from; `build_info.json` and `site_manifest.csv` (SHA-256 per file) describe the published files.
